## 🔫 Игра: SILENT ENTRY (стиль №4 — реалистичный тактический)

Top-down tactical shooter в духе Counter-Strike / Door Kickers: 5×5, раунды, экономика, закуп,
смена сторон, боты и мультиплеер по локальной сети. 10 видов оружия (+ нож), выпадение и подбор
оружия (G), настройки графики и переназначение всех клавиш.

| Карта | Режим | Описание |
|---|---|---|
| Gordon Hall · Офис | Бомба | A «Серверная», B «Архив» |
| Dust Yard · Пустыня | Бомба | Песчаные улицы и туннели в духе Dust |
| North Station · Зима | Заложники | Снежная станция, замёрзший пруд, сосны |
| Lost Temple · Джунгли | Заложники | Храм, река (замедляет), грязь, густые деревья |

На LAN-сервере карты идут по ротации после каждого матча (`START_MAP=` и `ROTATE_MAPS=0` — настройки).

### Запуск

```bash
npm install
npm start            # сервер на http://localhost:3000
```

- **Соло:** открой страницу → «Играть с ботами» (сервер для этого не нужен — симуляция идёт в браузере).
- **LAN:** запусти `npm start` на своём ПК, друзья в той же Wi-Fi сети открывают
  `http://<IP-твоего-ПК>:3000` (сервер печатает адрес при старте) → «Играть по сети / LAN».
  Свободные слоты добиваются ботами. Сложность ботов на сервере: `BOT_DIFFICULTY=hard npm start`.

### Управление

WASD — движение · мышь — прицел · ЛКМ или Пробел — огонь · ПКМ (держать) — прицел AWP/SSG · Shift — тихий шаг ·
R — перезарядка · E — действие (плент/дефьюз/заложник/обмен оружия) · G — выбросить оружие · B — закуп ·
1 — основное · 2 — пистолет · 3 — нож · 4 — граната (повторно — сменить тип) · Tab — счёт · Esc — меню/пауза.
Все клавиши переназначаются в ⚙ Настройки (там же — графика, частицы, свет, цифры урона, FPS, звук).

### Архитектура

| Файл | Роль |
|---|---|
| `public/sim.js` | Общая симуляция: карта, физика, оружие, раунды, бомба, ИИ ботов (A*, тактика). Работает и в браузере, и на сервере |
| `server.js` | HTTP + WebSocket: авторитетный LAN-сервер, 30 тиков/с, туман войны на сервере |
| `public/client.js` | Canvas-рендер: динамический свет, полигон видимости, фонарь, эффекты, синтезированный звук, HUD |
| `test/sim-test.js` | Автотест ядра: связность карты + полный матч ботов (`npm run test:sim`) |
