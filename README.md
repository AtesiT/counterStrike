## 🔫 Игра: SILENT ENTRY (стиль №4 — реалистичный тактический)

Top-down tactical shooter в духе Counter-Strike / Door Kickers: 5×5, раунды, экономика, закуп,
бомба на точках A «Серверная» и B «Архив», смена сторон, боты и мультиплеер по локальной сети.

### Запуск

```bash
npm install
npm start            # сервер на http://localhost:3000
```

- **Соло:** открой страницу → «Играть с ботами» (сервер для этого не нужен — симуляция идёт в браузере).
- **LAN:** запусти `npm start` на своём ПК, друзья в той же Wi-Fi сети открывают
  `http://<IP-твоего-ПК>:3000` (сервер печатает адрес при старте) → «Играть по сети / LAN».
  Свободные слоты добиваются ботами. Сложность ботов на сервере: `BOT_DIFFICULTY=hard npm start`.

### Управление

WASD — движение · мышь — прицел · ЛКМ — огонь · ПКМ (держать) — прицел AWP · Shift — тихий шаг ·
R — перезарядка · E — плент/дефьюз · B — закуп · 1/2 — оружие · 3 — граната (повторно — сменить тип) · Tab — счёт ·
Пробел после смерти — сменить наблюдаемого союзника.

### Архитектура

| Файл | Роль |
|---|---|
| `public/sim.js` | Общая симуляция: карта, физика, оружие, раунды, бомба, ИИ ботов (A*, тактика). Работает и в браузере, и на сервере |
| `server.js` | HTTP + WebSocket: авторитетный LAN-сервер, 30 тиков/с, туман войны на сервере |
| `public/client.js` | Canvas-рендер: динамический свет, полигон видимости, фонарь, эффекты, синтезированный звук, HUD |
| `test/sim-test.js` | Автотест ядра: связность карты + полный матч ботов (`npm run test:sim`) |
